CSLox is ment to be a faithful C# implementation of the interpreter for the Lox programming language.

After the implementation is finished, further steps will be to create a new programming language starting from Lox as a base, and to make a compiler for it. Lastly, the compiler will be rebuilt in zig, in an attempt to improve performance over the first iteration.

This is a practice project starting from the book "Crafting Interpreters" from the one and only Robert Nystrom, which will guide the implementation of the first interpreter as I translate the code to C#.
The point of this project is getting comfortable with how an interpreter and a compiler work, learn zig, and to work on my own coding and optimization in the process.
